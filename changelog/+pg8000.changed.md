PostgreSQL now uses pg8000 (pure Python, BSD-3) by default: dialect URL `postgresql+pg8000`, extra `postgres` installs `pg8000` instead of `psycopg[binary]`, and every platform including Windows ARM64 gets PostgreSQL support. psycopg stays available with the new extra `postgres-psycopg` and the profile key `driver: psycopg` (SPEC decision D15). The real database error text and the SQLSTATE mapping are unchanged; differences (connect errors now carry the SQLSTATE, only `application_name` is allowed in `query`/`connect_args`, TLS through `ssl_certs_dir` as an `ssl.SSLContext`, values such as `infinity` come back as text) are recorded in `docs/WIRE_SHAPES.md` section 16. A profile without `driver` on a minion that has only psycopg installed now answers `[E_DRIVER_MISSING]`; set `driver: psycopg` or install `saltext-sqlx[postgres]`.
